# josedihego.net

Personal and teaching site of Prof. José Dihego (IFBA), served at [josedihego.net](https://josedihego.net).

Built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme, hosted on GitHub Pages.

- Pages live in `_pages/`; top navigation in `_data/navigation.yml`.
- Custom styles: `assets/css/custom.css` (loaded site-wide via `_includes/head/custom.html`).
- Course calendars: `assets/pdfs/`.

Run locally: `bundle install && bundle exec jekyll serve`
